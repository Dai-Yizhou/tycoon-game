# 快速上手（协作者）

三步即可从"没有想法"到"地图入库"。全程在 AI 对话里完成，不需要接触 GitHub 网页或本地工具。

## 第 1 步 / 打开 AI

用手机/网页版打开 Trae，进入本地图仓库的工作会话。什么都不用配置。

## 第 2 步 / 用自然语言描述格子

直接说你要什么，Agent 会自动产出 JSON。例句：

> "我要一个 property 格子，id=5，价格 100，租金 10/20/30/40，可升 3 级。"

> "我要一个 supply 格子，经过时 +10 现金。"

> "我要一个 investment 格子，任意玩家踩到 event 格时给股东分 5 现金。"

如果你**不知道怎么描述**，直接问：

> "怎么描述一个格子？"

Agent 会引导你。它可能会追问缺失的信息——照实回答即可。

## 第 3 步 / 说"提交"

确认无误后说：

> "提交"

Agent 会写入并入库到地图仓库，返回 commit hash。

## 出错了？直接贴 JSON

如果对话流程不顺，也可以**直接贴 JSON 文本**发给开发者（例如微信）。开发者侧会负责校验与入库。

## 常问

- **要不要学 JSON？** 不用。正常流程你只说话。
- **要不要懂 UCT？** 不用。Agent 帮你生成正确的正负号与字段。
- **校验不过怎么办？** Agent 会告诉你缺什么，补上再提交。
