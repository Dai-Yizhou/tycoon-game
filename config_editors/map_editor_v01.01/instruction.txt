# 地图编辑器

## 📖 地图作者说明书

### 一、工具简介

地图编辑器是一个可视化工具，用于创建和编辑“大世界大富翁”游戏的地图。你可以自由放置格子、定义格子的所有属性（名称、类型、价格、租金、行为文件、图标等），并导出为游戏可读的 JSON 文件。

---

### 二、快速上手

#### 第一步：加载属性模板

点击工具栏的 **“📋 属性模板”** 按钮，选择一个符合格式的 JSON 文件（示例见后文）。模板定义了每个格子包含哪些属性，以及每个属性的数据类型和编辑方式。

#### 第二步：创建格子

在画布**空白处单击**，即可创建一个新格子。新格子会出现在鼠标点击位置，并自动填充模板定义的默认值。

#### 第三步：编辑格子

**单击**格子将其选中，右侧面板会显示该格子的所有属性。修改任意属性后，数据会自动保存（浏览器本地存储）和记录（支持撤销/重做）。

**双击**格子可快速编辑“名称”属性（如果模板中定义了 `name` 字段）。

#### 第四步：连接格子

点击工具栏的 **“🔗 连线”** 按钮进入连线模式。依次点击两个格子，即可建立双向连接（用于交通枢纽、传送点等）。

#### 第五步：导出地图

点击 **“⬇️ 导出”** 按钮，选择保存位置和文件名（建议 `map.json`），即可导出完整地图数据。

### 三、详细操作说明

#### 3.1 工具栏按钮

| 按钮 | 功能 |
|------|------|
| 📄 新建 | 清空当前地图（会提示确认） |
| ⬇️ 导出 | 导出地图为 JSON 文件，可选择保存位置 |
| 📂 导入 | 导入之前导出的 JSON 地图文件 |
| ↩️ / ↪️ | 撤销 / 重做（也支持 `Ctrl+Z` / `Ctrl+Shift+Z`） |
| 📂 （属性名） | 由模板动态生成，用于导入对应属性的文件列表 |
| 🖼️ 背景 | 导入背景图片，辅助地图布局 |
| ▦ 网格 | 显示/隐藏辅助网格 |
| − / + / ⟲ | 缩放 / 重置缩放（也支持 `Ctrl+` / `Ctrl-` / `Ctrl0`） |
| 🔗 连线 | 切换连线模式 |

#### 3.2 画布交互

| 操作 | 效果 |
|------|------|
| **单击空白处** | 创建新格子 |
| **单击格子** | 选中格子，右侧显示属性面板 |
| **双击格子** | 选中并聚焦“名称”属性（如果存在） |
| **拖拽格子** | 移动格子位置 |
| **滚轮/双指滑动** | 平移画布 |
| **Ctrl + 滚轮或Ctrl/Cmd + +/-** | 缩放画布 |

#### 3.3 属性面板

属性面板显示当前选中格子的所有属性，包括：

- **序号**：格子的id（从0开始连续的唯一编号）
- **位置信息**：格子的 X、Y 坐标（只读）
- **连线信息**：当前格子的目标连线列表（只读）
- **自定义属性**：由模板定义的所有属性

属性的编辑方式取决于模板定义：

| 模板标记 | 编辑方式 |
|----------|----------|
| `0` | 只读（灰色不可编辑） |
| `1` | 普通输入框（文本/数字） |
| `2` | 下拉选择（从导入的文件夹中选择文件） |
| `[...]` 数组 | 下拉选择（从给定的数组元素中选择） |
| `[]` / `[0]` / `[""]` | 数组输入（可添加/删除元素） |

#### 3.4 数组属性操作

- **添加元素**：点击 **“+ 添加元素”** 按钮
- **删除元素**：点击元素右侧的 **“✖️”** 按钮
- **快捷添加**：在任意数组输入框中按下 **`Alt+Tab`**，自动在末尾添加一个新元素并聚焦

### 四、属性模板格式

模板文件是一个包含**两个对象**的数组：

```json
[
  {
    "属性名1": 类型示例,
    "属性名2": 类型示例,
    ...
  },
  {
    "属性名1": 编辑标记,
    "属性名2": 编辑标记,
    ...
  }
]
```

#### 4.1 第一项：类型定义

| 类型示例 | 含义 |
|----------|------|
| `"文本"` | 文本属性 |
| `0` | 数字属性 |
| `true` / `false` | 布尔属性（下拉选择“是/否”） |
| `[0]` | 数组属性（数字数组） |
| `[""]或[]` | 数组属性（字符串数组，显式声明） |

#### 4.2 第二项：编辑标记

| 标记 | 含义 |
|------|------|
| `0` | 只读（显示但不可编辑） |
| `1` | 可编辑（输入框） |
| `2` | 从文件夹选择（下拉选择，需导入对应文件夹） |
| `["选项1", "选项2"]` | 下拉选择（从给定选项中选择） |

#### 4.3 模板示例

```json
[
  {
    "name": "",
    "type": "property",
    "price": 0,
    "rent": [0],
    "description": "",
    "behavior": "",
    "icon": "",
    "level": 0,
  },
  {
    "name": 1,
    "type": 1,
    "price": 1,
    "rent": 2,
    "description": 1,
    "behavior": 2,
    "icon": 2,
    "level": 0,
  }
]
```

解析结果：

| 属性 | 类型 | 编辑方式 |
|------|------|----------|
| `name` | 文本 | 输入框 |
| `type` | 文本 | 输入框 |
| `price` | 数字 | 数字输入框 |
| `rent` | 数组（数字） | 数组控件 |
| `description` | 文本 | 输入框 |
| `behavior` | 文本 | 从“行为”文件夹下拉选择 |
| `icon` | 文本 | 从“图标库”文件夹下拉选择 |
| `level` | 数字 | 只读 |

### 七、常见问题

**Q：为什么有些属性是灰色的？**  
A：模板中该属性标记为 `0`（只读），不可编辑。

**Q：导入文件夹后下拉列表没有更新？**  
A：请确保选择的是一个**文件夹**（而非单个文件），且文件夹内包含对应属性的文件。导入后需要**重新选中格子**刷新面板。

**Q：数组元素添加后消失了？**  
A：请确保在数组中填写内容后，点击了输入框外部或按 `Tab` 键，数据会自动保存。

**Q：导出的文件在哪里？**  
A：使用 Chrome 浏览器会弹出保存对话框，可选择保存位置；其他浏览器会自动下载到默认下载目录。

# 🔌 开发者说明书

## 一、文件格式概述

地图编辑器导出的 JSON 文件是一个**对象数组**，每个对象代表一个格子。格式示例如下：

```json
[
  {
    "id": 0,
    "x": 747,
    "y": 282,
    "destinations": [2],
    "name": "起点",
    "type": "start",
    "price": 0,
    "rent": [],
    "description": "游戏起点",
    "behavior": "",
    "icon": "",
    "level": 0,
  },
  // ... 更多格子
]
```

---

## 二、内置字段（所有导出文件均包含）

| 字段 | 类型 | 必含 | 说明 |
|------|------|------|------|
| `id` | `number` | ✅ | 格子唯一标识符，从 0 开始连续编号 |
| `x` | `number` | ✅ | 格子在画布上的 X 坐标（逻辑坐标） |
| `y` | `number` | ✅ | 格子在画布上的 Y 坐标（逻辑坐标） |
| `destinations` | `number[]` | ✅ | 连线目标格子 ID 列表（双向连接，需双向存储） |

---

## 三、自定义字段（由模板决定）

自定义字段的数量、名称、类型和含义**完全由属性模板定义**。游戏开发者应要求地图制作者提供对应的模板文件，以便了解所有字段。

### 3.1 字段类型映射

| 模板类型 | JSON 导出类型 | 说明 |
|----------|---------------|------|
| 文本 (`""`) | `string` | 字符串 |
| 数字 (`0`) | `number` | 数字 |
| 布尔 (`true`/`false`) | `boolean` | 布尔值 |
| 数组 (`[]`) | `array` | 数组（元素类型由模板决定） |

### 3.2 常见自定义字段约定（建议）

虽然字段由模板定义，但建议地图制作者遵循以下命名约定，以便游戏逻辑统一处理：

| 字段名 | 建议类型 | 用途 |
|--------|----------|------|
| `name` | `string` | 格子显示名称 |
| `type` | `string` | 格子类型（`property` / `event` / `transport` / `monument` / `start` / `jail`） |
| `price` | `number` | 购买价格 |
| `rent` | `number` 或 `number[]` | 租金（单级或多级） |
| `description` | `string` | 描述文本 |
| `behavior` | `string` | 行为文件名（从 `behavior` 文件夹选择） |
| `icon` | `string` | 图标文件名（从 `icon` 文件夹选择） |
| `level` | `number` | 当前建筑等级 |
| `upgradeCost` | `number` 或 `number[]` | 升级费用 |
| `owners` | `number[]` | 持有者 ID 列表（合租支持） |
| `bonusAmount` | `number` | 纪念碑发放金额 |

## 四、读取示例（JavaScript/Node.js）

```javascript
const fs = require('fs');

// 读取地图文件
const mapData = JSON.parse(fs.readFileSync('map.json', 'utf-8'));

// 构建格子索引
const cells = {};
for (const item of mapData) {
  cells[item.id] = item;
}

// 获取某个格子的属性
const cell = cells[0];
console.log(`格子 #${cell.id}: ${cell.name} (${cell.type})`);
console.log(`位置: (${cell.x}, ${cell.y})`);
console.log(`价格: ${cell.price}, 租金: ${cell.rent}`);
console.log(`连线: ${cell.destinations.join(', ')}`);

// 遍历所有格子
for (const item of mapData) {
  // 处理每个格子
  processCell(item);
}

function processCell(cell) {
  // 根据类型处理
  switch (cell.type) {
    case 'start':
      // 起点处理
      break;
    case 'property':
      // 地产处理
      break;
    case 'event':
      // 事件格处理
      break;
    case 'transport':
      // 交通枢纽处理
      break;
    case 'monument':
      // 纪念碑处理
      break;
    case 'jail':
      // 监狱处理
      break;
    default:
      // 未知类型
  }
}
```

## 五、读取示例（C++）

```cpp
#include <nlohmann/json.hpp>
#include <fstream>
#include <iostream>
#include <vector>

using json = nlohmann::json;

struct Cell {
    int id;
    double x, y;
    std::vector<int> destinations;
    std::unordered_map<std::string, json> extra; // 自定义属性
};

std::vector<Cell> loadMap(const std::string& filename) {
    std::ifstream file(filename);
    json data;
    file >> data;

    std::vector<Cell> cells;
    for (const auto& item : data) {
        Cell cell;
        cell.id = item["id"].get<int>();
        cell.x = item["x"].get<double>();
        cell.y = item["y"].get<double>();
        cell.destinations = item["destinations"].get<std::vector<int>>();

        // 提取自定义属性
        for (auto it = item.begin(); it != item.end(); ++it) {
            const std::string& key = it.key();
            if (key != "id" && key != "x" && key != "y" && key != "destinations") {
                cell.extra[key] = it.value();
            }
        }
        cells.push_back(cell);
    }
    return cells;
}

int main() {
    auto cells = loadMap("map.json");
    for (const auto& cell : cells) {
        std::cout << "格子 #" << cell.id;
        if (cell.extra.count("name")) {
            std::cout << " " << cell.extra["name"].get<std::string>();
        }
        std::cout << std::endl;
    }
    return 0;
}
```

## 六、字段访问注意事项

1. **`destinations` 是双向的**：如果 A 连接到 B，则 A 的 `destinations` 包含 B，B 的 `destinations` 也包含 A。

2. **自定义字段可能缺失**：如果地图制作者在编辑时未填写某属性，导出时该属性会被补全为默认值（空字符串、0、空数组或 `false`），但**不会缺失**。

3. **数组元素类型**：数组属性导出时，元素类型由模板决定。数字数组导出为数字（如 `[100, 200]`），字符串数组导出为字符串（如 `["a", "b"]`）。

4. **坐标范围**：`x` 和 `y` 是逻辑坐标，实际像素位置需要乘以当前缩放值。如果游戏需要在不同分辨率下渲染，建议将坐标作为比例值使用。

## 八、地图级计税配置

计税配置不属于格子属性模板，而属于导出的 `map-meta.json`。在 `config` 下维护完整的 `taxConfig` 对象：`wealthTaxRate`、`propertyTaxRate`、`investmentTaxRate` 是 0 到 1 的小数比例；`minWealthForTax`、`minPropertyValueForTax` 是非负免税阈值；`taxInterval` 是正数毫秒。服务端不会从源码补齐缺失字段，配置不完整或非法时拒绝启动。

导出的 JSON 文件格式稳定，未来可能扩展的字段均会向后兼容。建议游戏开发者：

1. 忽略未知字段，避免因新增字段导致解析失败。
2. 对缺失的自定义字段使用合理的默认值。
3. 使用 `id` 作为格子唯一标识，不要依赖数组索引。
