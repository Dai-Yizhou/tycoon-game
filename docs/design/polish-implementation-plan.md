## 2. 已对齐的关键决议（疑义 → 结论）

### 2.1 黑屏转场的取舍（修订 §9.2）

- §9.2 原文要求：内测前"移除黑屏转场"，主题切换直接 `applyGamePageThemeTokens`。
- **对齐结论**：黑圆转场**不全删**，收敛为**两个触发点**——
  1. **进入游戏**：点击进入按钮时即**已是全黑**，游戏页出现后**只播放露出动画**（黑圆收缩）；**不**再播放"进入黑屏"的扩散动画（否则会在页面出现后重新播一次转场）。
  2. **棋子传送**（无路径瞬移/跨区跳变）：仅传送目标格与当前格不同时触发，顺序为**进入黑屏 → 盖满后移动 → 露出**。
- **主题切换（区域色令牌变化）不再触发黑圆盖屏/露屏**：`applyRegionTheme` 里去掉 `gameEffects.onThemeChange` 的 covering→apply→revealing，直接应用令牌。
- **回退/保留**：`appliedRegionThemeId` 去重、`localStorage(SAVED_REGION_THEME_KEY)` 沿用机制全部保留；移除的只是盖屏转场逻辑，主题解析/注入本身不变。
- 复用点：进入游戏与传送共用同一圆形遮罩实现（`CssTransitionEffectHooks` 的 covering→covered→revealing 状态机），不改其内部状态机。

### 2.2 图标暂缓

- 8 类型图标全部延后；本次只做文字弱化 + 其他项。不引入图标库（守"不引资产"纪律）。

### 2.3 拼图块点数呈现

- 复用现有按钮簇显示"已移动/总步数"，完成掷骰移动后自动关闭；与该格属主无关，仅本玩家移动期可见。

### 2.4 范围全量

- P0–P3 全部纳入本期计划；§3 重构不纳入（难度≈设计工具、强耦合地图编辑，ROI 非简陋感）。详见 `frontend-polish.adoc.md §8.3`。

## 3. 各实施项边界与定义

### 3.1 弱化文字（P0）

- **目标**：格子内文字由"主角"降为"辅助"，为后续图标/留白腾位。
- **边界（已对齐）**：地图上的格子方框**只显示名称 + 类型**（不含价格等），居中两行布局（type 上、name 下），调整字号/字距使观感协调；**不删信息**——悬停仍可查看完整信息（沿用 hover 限制：仅本玩家当前格可 hover）。
- **下界**：名称不得低于可辨识阈值（不因弱化而无法辨认自己站在哪格）；`prefers-reduced-motion` 不适用（非动效项）。
- **锚点**：`InteractiveMapSurface.ts` 节点文本（`map-node__type / map-node__name`）、`style.css`。

### 3.2 zhi t点数提示（P0）

- **语义**：移动期显示"已移动 / 总步数"。
- **实现**：复用 `act-bar` 按钮簇（非新建独立组件）；进入移动序列时j在掷骰头ani右侧显示，到达目标后隐藏。
- **边界**：仅本玩家移动期；数据取自权威路径/步数（服务端下发），不做本地推算；不阻塞其他操。
- **协调**：与 §3.6 棋子减速同一时间窗，避免重复元素叠加。

### 3.3 控件/格子/HUD 放大（P0）

- **目标**：桌面端控件、地图格子、HUD 元素适当放大，提升可读与触达。
- **决策（已对齐）**：**当前不重点考虑移动端，先把桌面端做好**；移动端仅做不挤爆的兜底（≤700px 回缩小尺寸），不做精细打磨。
- **范围**：① 控件（掷骰/行动按钮等）；② **地图格子**（格框尺寸与文字同步放大，需防相邻重叠）；③ **HUD**（顶栏/动作条/聊天/面板字号与内边距）。
- **实现**：纯 CSS（媒体查询/断点）+ 既有 `--motion-*` 令牌；不引库。只做尺寸/间距/命中区/字体，不改布局结构、不动交互语义；与主题令牌 `--gp-*` 消费兼容。

### 3.4 连线方向指示（P0，§9.1）

- **语义来源**：地图数据 `destinations`。
  - 单向：`A.destinations` 含 B 且 `B.destinations` 不含 A → 方向 A→B。
  - **双向：双方互含 → 两端各画一个箭头**（A→B 与 B→A 各一条带箭头线段）。
  - 空/缺失 → 不画线（现状不变）。
- **渲染（已对齐）**：无向去重后按方向绘制**带箭头线段**（非纯裸线）；箭头置于**目标格边缘**（线段按约一个格子半径向目标中心内收，避免箭头被目标格子方框盖住——实测不内收会看不到箭头）；固定箭头用**单个 SVG `<marker>`** 复用，`orient=auto` 自动定向。
- **弱化纪律**：箭头小、低对比、与 `map-link` 同色系，不喧宾，但保证可见。
- **边界**：只解决单/双向歧义；不新增多路径/弯路；不强化连线基线；折叠自环/重复对行为不变。
- **锚点**：`InteractiveMapSurface.ts` 的 links 构建段（含 `isBidirectional(a,b)` + marker 挂载 + 端点内收）。

### 3.5 favicon + rentfree 顶中节点（P1）

- **favicon**：`favicon.ico` / `<link rel=icon>`，与主题/品牌一致。
- **rentfree 顶中节点**：技能节点区顶中放置 rentfree 相关内容并补网页图标；提升节点可辨识。
- **边界**："顶中节点"＝在地图/HUD 既定技能节点位置补明确标识；不做新地图节点；不引资产（图标用代码/文本，守纪律）。

### 3.6 棋子段落感 + 减速（P1，§9）

- **目标**：棋子滑行带"段落感 + 收尾减速 + 落地手感"（观察真实移子）。
- **实现**：接现有 move hooks / 移动动画；参照 `piece-motion-variants` 母版规格（30×56、3px 墨描边、inset 3px、`transform-origin: bottom center`）。
- **边界与协调**：**服务端权威快照纠正优先**——减速/段落分帧不得被"跳"打断逻辑；幂等、可被快照归位覆盖。不引库（不用 GSAP）。
- **注意**：与 §2.1 传送黑屏转场正交：正常走格走的动画不变，传送走黑屏转场。

### 3.7 数值滚动 + 底色呼吸（P1）

- **目标**：数值变化有视觉反馈，但不一直滚动/不造成视觉干扰。
- **实现**：先实现底色呼吸：数值变化时快速提亮底色，然后缓慢回归。**仅本地结算瞬时滚动** ；滚动结束回稳。
- **边界**：非全量广播；仅本玩家本地结算事件触发；克制（不每帧动、不持续闪烁）；`prefers-reduced-motion` 可整体关。

### 3.8 轻量音效（P2）

- **目标**：掷骰 / 落子 / 增减分 / 破产 四类反馈音。
- **实现**：**WebAudio 程序合成**（`OscillatorNode`/`BufferSource`），零"资产文件"。
- **边界**：四类即可，不做持续音乐；配**全局静音**开关；`prefers-reduced-motion` 时关；显式 init（用户手势后启动 AudioContext）。

### 3.9 背景阴影分层（P2）

- **目标**：“格子躺桌面 / 棋子浮起"两档、统一光源、暖调、克制、浮动感。
- **实现**：CSS `drop-shadow` + `transition`；数值做令牌（随主题），依照当前游戏时间计算光照投影角度。
- **边界**：无粒子；不做逐对象方向阴影；GPU 合成；`prefers-reduced-motion` 关。

### 3.10 附加交互：拖移/手势/快照键（P3）

- **实现**：**Pointer Events**（通吃鼠标/触屏/笔）+ 现有 `cellChoice` + CSS transform 过渡；不引库。
- **边界**：保留按钮簇兜底；桌面/移动同一套逻辑；快照键带提示文本（避免纯图标辨识）。

### 3.11 昼夜光照呼吸（P3，§4 定义）

- **目标**：昼夜＝"整套基色 + 夜晚光照叠加层"，连续系数控强度，不维护两套完整主题。
- **实现**：`localProgress`（客户端 `cycleStartTime`+`serverTimeOffset` 平滑函数）逐帧对叠加层 `opacity`/blend 插值；客户端时间即可，不严格校验。
- **边界**：与区域色**正交可叠加**；区域定基色，昼夜在基色上光照；`prefers-reduced-motion` 关。

## 4. 实施分组时序（建议）

> 分组原则：先"消灭简陋/挡点"（性能低、确定），后"触感增强/可选"（可独立开关，不进本期也不阻塞）。

| 批次 | 项 | 依赖/说明 |
|---|---|---|
| **B1 挡点** | 3.1 弱化文字 · 3.3 控件放大·移动可读 · 3.4 连线方向 | 纯 CSS/SVG，低风险，先行 |
| **B2 移动质感** | 3.2 拼图块点数 · 3.6 棋子段落感+减速 | 共享 move 窗口，一起调 |
| **B3 视觉反馈** | 3.7 数值滚动+呼吸 · 3.9 阴影分层 | 同属"克制动效"，令牌化 |
| **B4 品牌/信息** | 3.5 favicon + rentfree 顶中节点 | 独立 |
| **B5 感官增强** | 3.8 轻量音效（P2） · 3.10 附加交互（P3） · 3.11 昼夜呼吸（P3） | 均可独立开关，靠后不阻塞 |
| **B0 转场收口（前置）** | §2.1 黑屏转场收敛 | 先改，避免后续主题切换路径再叠加 |

> 每批完成即跑客户端 tsc + jest（110 用例），并手测对应项后再进下一批。B0 前置因为会改动 `applyRegionTheme` 路径，后续批次如不先做会叠加新逻辑。
