01 / 动作变式

所有动作变式不改变基础尺寸；躯干填充从边框内侧开始，避免颜色挤压边框。

站立

01

形态：头部居中，梯形垂直
适用：默认待机

左倾

02

形态：头部与躯干整体向左倾 8deg
适用：移动前摇

右倾

03

形态：整体向右倾 8deg
适用：移动前摇

前探

04

形态：头部前偏 3px，躯干上缘前移 2px
适用：选择方向

后仰

05

形态：头部后偏 3px，底边保持稳定
适用：受阻 / 暂停

举牌

06

形态：右上方加 12×10px 小牌
适用：提示 / 轮到玩家

聚拢

07

形态：头部与躯干向中心压缩 2px，高度不变
适用：组队 / 确认

跳跃

08

形态：整体上移 6px，底部留 6px 空隙
适用：掷骰成功反馈；不是画脚

03 / 描边与填充参数表

轮廓3px solid #1A1A1A
头部直径 22px，圆形
躯干上底 16px / 下底 26px / 高 30px
总框约 30px × 56px
内部填充padding / inset: 3px
盒模型box-sizing: border-box
层级禁止禁止 fill 覆盖 border；纹理仅在内填充层
动作基点transform-origin: bottom center
尺寸约束变式不改变基础尺寸

纹理建议：呢料 / 棉布使用细密 45deg 斜线，透明度 12–16%，不可进入描边层。夜型可在深墨外增加 1px 暗金外圈，但外圈不能当作轮廓。
