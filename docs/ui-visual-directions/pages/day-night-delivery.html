昼夜变换：棋子与地图视觉规范

桌面静态交付页 · 同一套重描边、地域材料语法在不同光照时段的保真规则

01

系统原则

昼夜只改变光照、表面、纹理强度、对比度、状态色与辅助文字。不得改变棋子几何、连线宽度、格子功能编码、信息层级或交互位置；所有时段都保持厚重深墨描边与 1900 年代地域材料感。

DAY / 昼

清晰纸面与高可读对比。基准：环境光充足，浅纸底承接深墨轮廓。

DUSK / 黄昏

暖侧光压低表面。基准：日落后、夜间状态色尚未主导时的过渡层。

NIGHT / 夜

深蓝材料面与暗金定位。基准：低照度，关键路径和选中轮廓承担导向。

04

实施规则

  1. Canvas 与 DOM 必须共用同一份语义令牌：几何、线宽、状态色、表面强度和文本层级不可分叉定义。
  2. 昼夜切换使用 CSS class 或主题对象；主题仅覆盖令牌值，棋子结构不在主题中重建。
  3. 所有纸纹与呢料斜线必须裁切在内侧填充中，不得越过 3px 描边；仅允许 repeating-linear-gradient 作为纹理来源。
  4. 实现 prefers-reduced-motion：主题与棋子动效均降为 0ms；夜间背景也停止变化。不得使用玻璃拟态、普通渐变、霓虹光晕、外部资源、图片、SVG 或 Canvas。
