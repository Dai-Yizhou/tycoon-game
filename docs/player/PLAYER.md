# 玩家手册

## 游戏概述

大富翁.io 是多人网页棋盘游戏。玩家掷骰移动，在岔路选择路径，购买和升级地产、参与投资、使用交通枢纽、修缮纪念碑，并与其他玩家组队和聊天。

## 当前操作

- **掷骰与移动**：按钮发送请求，服务端决定骰子、冷却、路径和最终落点；遇到岔路时选择合法方向。
- **地产**：停在可用地产时购买、升级、抵押或赎回，最终余额与所有权以服务端结果为准。
- **投资**：购买项目持股并接收服务端广播的收益或损失。
- **交通枢纽**：先获取当前目的地，再选择目标并支付费用。
- **纪念碑**：查询状态并在满足条件时修缮，繁荣度变化由服务端广播。
- **银行与破产**：贷款、还款、破产清算和重开均由服务端处理。
- **队伍与聊天**：通过队伍邀请/成员事件和系统、队伍、区域频道交流。

## 界面

顶部栏展示服务端投影的玩家数值、区域繁荣度和本地昼夜。左侧是聊天/通知，右侧是行动控件；棋盘由 Canvas 渲染器绘制，移动动画不改变服务端结果。

## 不属于当前功能的内容

当前版本没有 item、talent、achievement 三个运行时系统，因此没有对应的道具背包、天赋树、成就面板、天赋点或成就进度玩法。其他历史或规格文档中的这些描述不适用于当前版本。

## 数据与连接

客户端断线后连接状态和错误由页面显示；登录恢复取决于服务端配置的玩家存储。地图和规则由当前服务端加载的数据决定，不同地图可能提供不同的区域、时区和数值字段。
