区域一 · 棋子形态规范

基础形态：高梯形上接圆形。不画脚、不画腿、不画胶囊小人；整体更厚重。纯 CSS 绘制，底部可直接接地。

  • 圆形头部：直径 22px，居中
  • 梯形躯干：上底 16px、下底 26px、高 30px，居中接在头部下方
  • 轮廓：3px 深墨色实线（#1A1A1A）
  • 总尺寸：约 30×56px
  • 底部可直接接地，不留间隙

跨地域统一规则

棋子与连线形态跨地域不变，地域只切换色彩、字体、边框、材料暗示与动态节奏描述。
